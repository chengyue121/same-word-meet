# 同词相见

双人实时默契挑战。两个人进入同一房间，针对同一组提示词各自写下第一反应；相同的词会触发“同词相见”，结束后生成默契报告。

## 运行

```bash
npm start
```

打开 `http://localhost:4173`。同一局域网内的手机可以打开终端输出的 Network 地址，也可以自行部署到任意支持 Node.js 的服务器。

## 已实现

- 4 位房间号、邀请链接、双人实时等待与开局
- 日常心动 / 脑洞频道，10 题或 20 题
- 双方答题进度同步
- 同词匹配、默契百分比、逐词对照
- 移动端分享、复制房间号与结果文案
- 历史上一局摘要、桌面端手机框预览
- 无需构建工具，无第三方运行时依赖

## 说明

当前版本是可直接运行和部署的移动端 H5 小程序。房间数据保存在服务端内存中，服务重启后会清空；正式上线时可把 `server.mjs` 里的 `rooms` 存储替换成 Redis 或数据库，并将静态页面部署到 HTTPS 域名。
