# 同词相见

双人实时联想挑战。两个人从同一个起始词出发，每轮根据上一轮双方写下的两个词继续联想；如果这一轮写出同一个词就立即结束，否则进入下一轮，最多 10 轮。

## 运行

```bash
npm start
```

打开 `http://localhost:4173`。

## 已实现

- 4 位房间号、邀请链接、双人实时等待与开局
- 日常词 / 脑洞词起始频道
- 双人逐轮联想，实时等待对方作答
- 同词即结束，最多 10 轮自动结算
- 展示起始词与每一轮双方答案
- 移动端分享、复制房间号与结果文案
- 历史上一局摘要、桌面端手机框预览
- 无需构建工具，无第三方运行时依赖

## 说明

当前版本是可直接运行和部署的移动端 H5 小程序。房间数据保存在服务端内存中，服务重启后会清空；正式上线时可把 `server.mjs` 里的 `rooms` 存储替换成 Redis 或数据库，并将静态页面部署到 HTTPS 域名。
